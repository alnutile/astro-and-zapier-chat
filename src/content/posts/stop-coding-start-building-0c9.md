Why it might be time to ditch your code editor. In this episode, I talk about why building—not coding—is the skill that matters in 2025. Whether you're new to tech, running a business, or a long-time developer, this is your reminder that solving problems doesn't require code anymore—and that’s a good thing.

If you're learning to code, launching a startup, or hiring a dev—you need to hear this.

In this episode, I talk through:

- 
Why code is no longer the starting point

- 
The shift from developer to *builder*

- 
Tools like n8n, Supabase, Bolt.new, and Cursor

- 
How AI and no-code platforms are reshaping productivity

- 
The real job of a developer (hint: it’s not writing code)

I’ve spent 20+ years in dev—Laravel, PHP, Rails, you name it—and I’m telling you: I’ve never written *less* code, and I’ve never built *more* valuable tools.
