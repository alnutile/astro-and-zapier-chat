This week brought some of the biggest announcements in no-code and AI automation. Here’s your quick rundown of what matters:

## 🔥 Major Platform Updates

**Softr Workflows Launch**

- Native automation built directly into Softr—no need for external tools like N8n

- Workflows integrate seamlessly with your data and UI

- Makes Softr a true full-stack platform

- **Why it matters:** Eliminates the intimidation factor of switching between tools for automation

**Zapier Enterprise AI Orchestration**

- Connecting legacy systems with modern workflows using AI

- Orchestrating data and automations in one place with AI-powered data transformation

- **Why it matters:** Proof that enterprise AI adoption is about implementation, not failure

**Bubble.io AI-Powered Building**

- AI is now assembling Bubble’s pre-built blocks into applications

- Reduces the need to be a “master builder” to use Bubble effectively

- **Why it matters:** Makes powerful no-code tools accessible to non-technical users

**N8n Enterprise Cloud**

- AI chat-driven workflow building

- GitHub integration for source control

- **The question:** Can N8n compete with chat-first builders, or is it serving a different audience?

**Google Opal Expansion**

- Simple prompt-to-app building for internal teams

- Creates intranet-facing applications, not public websites

- **Why it matters:** Makes it easy for office staff to build and share tools quickly

**Microsoft 365 No-Code Tools**

- New app builder and workflow automation for the Microsoft ecosystem

- **The caution:** Avoid vendor lock-in, but worth considering for Microsoft-heavy organizations

## 🌐 MCP (Model Context Protocol) - The Week’s Biggest Story

**What is MCP?** A protocol that helps AI agents interact with backend systems without writing custom integration code. Instead of 200+ lines of API integration, you install an MCP server and the AI handles everything.

**This Week’s MCP News:**

- **GitHub MCP Registry** launched with 44 curated servers (Microsoft, Stripe, Unity, Notion, HashiCorp)

- **Enterprise governance features** for managing approved MCP servers

- **London Stock Exchange (LSEG)** partnered with Anthropic to bring financial data via MCP

- **Dify** (117k GitHub stars) added MCP protocol support

- **IBM i MCP Server** (beta) brings AS/400 legacy systems to AI agents

- **Microsoft Fabric MCP** (public preview) for data platform integration

**New MCP Servers This Week:**

- **DollhouseMCP** - AI persona switching

- **gotoHuman** - Human-in-the-loop approvals for AI automations

- **Zoom MCP** - Meeting management via natural language

- **Hostinger MCP** - Infrastructure automation

- **GitLab MCP** - Project management integration

**The Numbers:** 10,743+ MCP servers now available in community registries

**Security Alert:** Critical RCE vulnerability discovered in Figma MCP Server (10k+ stars)

## 📊 GitHub Trending: Open-Source No-Code

**Low-Code Platforms:**

- **NocoBase** (17k stars) - Low-code platform with real AI agents

- **ToolJet, Appsmith, Budibase** - Internal tools builders gaining traction

- **Refine.dev** - React-based dashboard framework (great for quick dashboard builds)

**AI Workflow & Agent Orchestration:**

- **n8n** (151k stars) - Still the leader

- **Dify** (117k stars) - Rising star with MCP support

- **Flowise, Kestra, Node-RED** - Workflow automation alternatives worth watching

**Smart Spreadsheets & Database Tools:**

- **Supabase** - Powerful but heavy

- **NocoDB** - Nice interface, lighter weight

- **BaseRow** - Another solid option

- **Teable** - UI for database management with integration options

**Pro Tip:** When evaluating GitHub projects, check the Insights tab to see if the community is still active. Stars can be misleading—look for recent pull requests and commits.
